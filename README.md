# LISTO AI

Micro-SaaS autônomo de listagens SEO para marketplaces.

## Como rodar
```bash
pip install flask flask-cors
python app.py   # backend :8021
python serve.py  # front+proxy :8080
```

## Deploy
- Frontend: Cloudflare Pages
- Backend: Render.com
- Pagamento: Stripe (simulado ou real)

Ver `INSTRUOES_DEPLOY.md` para detalhes.
